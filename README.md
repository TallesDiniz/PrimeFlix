# PrimeFlix

Um site que permite criar, excluir e visualizar uma lista com filmes em cartaz, mostrando link, trailer, capa do filme e a nota do filme segundo o imdb. Um projeto simples para praticar conceitos do React e também a prática de consumir uma API. 


# Tecnologias utilizadas:
- HTML
- CSS
- Javascript
- React
- Utilização de uma API
